对话与记录管理

  • 保留长对话里的重点

    固定关键消息，为长对话生成摘要。原文保存在本机，随时可查。

  • 导入 DeepSeek 对话

    导入聊天记录，接着原来的话题聊。历史记录可搜索、可导出。

  • 深度思考与联网搜索

    选择模型和思考强度，查看联网搜索结果的引用来源。

  • 图片与文档附件

    添加照片和文件，在对话记录中浏览附件。

按需同步

可以在设备间直连同步，也可以使用你自己的腾讯云 COS 私有存储桶。

隐私政策

  • 设备直连

    在两台设备上核对配对校验码。同步时可以合并内容，或选择以其中一台为准。

  • 腾讯云 COS

    将对话快照和备份同步到自己账户下的私有存储桶。
