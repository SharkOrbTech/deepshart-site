DeepSeek 对话 兼容手机和电脑。

使用自己的 DeepSeek API Key。对话历史保存在本机，需要时再同步。

前往 Gitee 下载 查看功能

对话与记录管理

  • 深度思考与联网搜索

    选择模型和思考强度，查看联网搜索结果的引用来源。

  • 图片与文档附件

    添加照片和文件，在对话记录中浏览附件。

  • 记忆与上下文

    固定重要消息、查看记忆，对长对话生成摘要并保留原文。

  • 搜索、导入与导出

    查找历史消息，导入 DeepSeek 对话，或导出一份副本。

按需同步

可以在设备间直连同步，也可以使用你自己的腾讯云 COS 私有存储桶。

隐私政策

  • 设备直连

    在两台设备上核对配对校验码。同步时可以合并内容，或选择以其中一台为准。

  • 腾讯云 COS

    将对话快照和备份同步到自己账户下的私有存储桶。

支持手机和电脑

  • iPhone
  • Android
  • macOS
  • Windows

Gitee V1.0.1 提供 Windows 和 Android 安装包。
